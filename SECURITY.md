# Security Policy

## Reporting a Vulnerability

Pravix analyzes pull request metadata and, in later phases, will interact
with GitHub repositories via an Action/App. If you discover a security
vulnerability, please **do not open a public issue**.

Instead, report it privately by opening a
[GitHub Security Advisory](../../security/advisories/new) on this
repository, or by emailing the maintainer directly (contact to be added
once the project has a dedicated email).

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce, if applicable
- Any suggested remediation

We aim to acknowledge reports within 5 business days. This policy will be
expanded with formal response-time commitments once Pravix moves past
Phase 0.
